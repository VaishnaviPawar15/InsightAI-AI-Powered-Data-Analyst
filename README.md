# InsightAI – AI-Powered Data Analyst 🤖

InsightAI is a Generative AI-powered data analysis application built with Python and Streamlit. It allows users to upload datasets, perform automated analysis, and interact with their data using natural-language questions.

## Features

- 📁 Upload CSV and Excel datasets
- 🧹 Automatic data cleaning
- 📊 Exploratory Data Analysis (EDA)
- 🎯 Automatic KPI generation
- 📈 Interactive Plotly visualizations
- 🔗 Correlation analysis
- 📅 Date and trend analysis
- 🏷️ Categorical analysis
- 🤖 Gemini-powered business insights
- 💬 Ask questions about your dataset using natural language
- 💡 AI-generated business recommendations
- 📥 Download cleaned datasets

## Tech Stack

- **Python**
- **Pandas**
- **NumPy**
- **Plotly**
- **Streamlit**
- **Google Gemini API**
- **Generative AI / LLM**
- **OpenPyXL**

## How It Works

```text
Upload Dataset
      ↓
Data Cleaning
      ↓
EDA & Dataset Profiling
      ↓
KPI & Visualization
      ↓
Gemini AI Analysis
      ↓
Natural Language Questions
      ↓
AI Insights & Recommendations

🤖 Generative AI

InsightAI uses Google Gemini to analyze dataset information and generate natural-language responses.

Users can ask questions such as:

Which category has the highest performance?
What are the major trends in the dataset?
What problems can you identify?
Give me business recommendations.
Summarize this dataset.

Supported Files
CSV (.csv)
Excel (.xlsx)

## ⚙️Installation

Clone the repository:

git clone https://github.com/VaishnaviPawar15/InsightAI-AI-Powered-Data-Analyst.git

Install the required libraries:

pip install -r requirements.txt

Set your Gemini API key as an environment variable:

GEMINI_API_KEY="your_api_key"

Run the application:

streamlit run app.py
